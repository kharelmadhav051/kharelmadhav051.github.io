Madhav Kharel Academic Website
================================

This folder is ready for GitHub Pages.

UPLOAD TO GITHUB
----------------
1. Open your repository:
   kharelmadhav051.github.io
2. Click "Add file" > "Upload files".
3. Upload the CONTENTS of this folder, not the ZIP file itself.
4. Make sure index.html is visible at the top level of the repository.
5. Commit the files to the main branch.
6. Your site should appear at:
   https://kharelmadhav051.github.io

HOW TO EDIT LATER
-----------------
Homepage and all text:
- Open index.html.
- Search for "EDIT:" comments.
- Change the text between the HTML tags.
- Commit the change.

Colors/layout:
- Open style.css.
- The main colors are at the top under :root.
- UAlbany-inspired purple is stored as --purple.

Profile photograph:
- Replace assets/madhav-lab.jpg with another JPG using the SAME filename.
- Or change the image filename in index.html.

CNSE logo:
- Replace assets/ualbany-cnse.png if needed.

CV:
- Replace Madhav_Kharel_CV.pdf with a newer PDF using the SAME filename.
- All CV links will continue working.

Add a publication:
- Open index.html.
- Find the "EDIT: PUBLICATIONS" section.
- Copy one complete <li> ... </li> publication entry.
- Paste it below another publication and edit the citation/link.

IMPORTANT
---------
Keep these items at the repository top level:
- index.html
- style.css
- Madhav_Kharel_CV.pdf
- assets folder

The website intentionally uses plain HTML/CSS so it remains easy to edit
without a website builder or special software.
